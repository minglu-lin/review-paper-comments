# 技术审阅标准

这是一份筛选问题的参考，不是必须逐项填满的清单。只把适用于当前论文且有证据的问题写入 comments。

先判断候选问题是否影响科学解释、证据强度或结论边界。计算实现细节可用于内部核查，但不因发现一个未报告的参数就另列意见。提交版说明“什么仍不清楚、为何重要”，通常不指定作者下一步采用哪套实验、计算或统计流程。

## 创新与主张

辨认实际新增的是理论、方法、可验证的机制解释、可靠数据还是应用场景。把“换材料/换参数/换拟合算法”和作者具体的新贡献区分开。声称前人已完成同样工作时，应读到对应一手文献并能指出重叠及差异；没有证据时用具体的比较请求，而不是宣布缺乏创新。

检验结论是否超过模型、材料、加载路径、尺度和参数空间所支持的范围。解释为何边界影响当前结论，不泛泛要求“提高普适性”。

## 物理机制与替代解释

- 观察到现象不等于识别了原因。区分曲线相关、应力/能量场证据、原子构型、缺陷演化和因果论证。
- 看是否隔离了相互耦合因素：例如晶界与孔洞/位错环、取向与界面反应、单泡与双泡、节点损伤与键损伤。
- 询问现有证据如何区分竞争机制，避免把相关性直接写成因果，也不默认指定某种对照、场分析或时序图。
- 比较同一物理过程的不同理论/计算方法是否在相同定义和加载条件下成立。
- 区分绝对量与相对变化、总体响应与局部指标、趋势一致与机制一致；指标或条件不同，先问其物理联系，不凭曲线趋势不同就断言矛盾。

## 模型、量纲与数值可靠性

- 核查与主结论相关的几何、边界、加载、离散、弛豫及关键参数；缺项先查补充材料，仅把影响结论判断或关键结果复现的缺口写入意见。
- 用独立量纲和数量级校验发现矛盾，如长度与体积、原子数与晶胞体积、无量纲时间/应变率与实际量纲映射。
- 假设应有适用条件：独立性/零相关、相干界面、均匀应力、随机取向分布等。检验其对主结果的影响，不把简化本身当作错误。
- 时间步、尺寸、网格、视界、随机种子或统计样本的敏感性，仅在会影响主结论时提出相应要求。
- 在使用软化、断键、热耦合或动态加载时，考虑能量收支、耗散、稳定性和非物理解。不能因为正文未讨论就断言违反热力学。

## 针对常见方法

| 方法 | 重点核查 | 避免的武断推断 |
|---|---|---|
| MD / 冲击 / 缺陷 | 势函数适用范围、弛豫与系综、加载卸载实现、应力定义、尺寸/应变率效应、缺陷识别和对照 | 不把某一旧稿的活塞处理或某种势函数限制当作所有模型的硬性规则 |
| 能垒 / NEB / GSF | 初末态、反应路径、外加应力、收敛、参考能量、理论公式与计算是否可比较 | 不把不同元素的原子势能直接视作位错形核/运动的活化能 |
| 晶体塑性 / 统计形核 | RVE/RVU 代表性、取向/形貌随机化、界面参数、相关性假设、局部与远场微结构 | 不因使用统计模型就机械要求某一种相关系数 |
| PFC / 相场 | 无量纲量与物理尺度、扩散/应力机制、形貌演化、边界与实验可比观测量 | 不要求无法成立的唯一时间映射而忽略模型的有效尺度限制 |
| 近场动力学 / 动态断裂 | 本构与损伤耦合、应变率/温度范围、视界/离散、耗散、裂纹路径与宽度、定量基准 | 不把视觉一致或数值稳定等同于准确性/热力学一致性 |
| MD + ML | 数据拆分与同源样本泄漏、物理状态覆盖、取向表征、外推、误差分布及机制佐证 | SHAP 是模型解释，不能独立证明物理因果；整数编码的影响依算法而异，不能断言所有模型必然失效 |
| 气泡 / 空化 / 流固相关 | 压力与冲量定义、相位和传播时序、边界反射、单泡基准、量纲参数 | 应解释转变阈值与因果时序，不能只复述图片变化 |

## 验证强度

“趋势一致”“图像相似”和定量吻合分开判断。检查比较量的定义、尺度和工况是否一致，询问现有比较在多大程度上支持所声称的预测能力。只在某一量确为结论成立所必需时指出具体证据缺口，不罗列作者应新增提取的指标。

有实验时检查是否真正定量对照；无实验时辨认解析解、可信基准、独立方法等已有证据的支持程度。模型中间量与实验最终响应之间的联系需要物理依据。要求新实验或全新方法前，先判断是否为检验核心结论所必需、是否可由澄清或限定主张回答，并避免扩展成后续研究计划。

## 判断尺度

| 倾向 | 依据 |
|---|---|
| 接收 | 核心论证和验证充分，没有必须修复的实质问题；不要为了凑数编造缺陷 |
| 小修 | 结论基本可靠，主要需要澄清、局部分析或展示修正 |
| 大修 | 机制归因、关键假设或核心验证仍有可修复的实质缺口 |
| 拒稿 | 经核实的贡献或可靠性问题使稿件无法通过合理修订达到目标；说明主要依据 |

目标期刊适配与科学有效性是不同判断。不得从历史某次拒稿推导所有类似工作都不够格。
